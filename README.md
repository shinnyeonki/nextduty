# NextDuty - 근무 이동 알림 앱

이 프로젝트는 정해진 편성표에 따라 근무지를 이동해야 하는 사용자를 위한 자동 알람 서비스입니다. 사용자가 어떤 상황(화면 꺼짐, 다른 앱 사용 중 등)에서도 이동 알림을 명확히 인지하도록 설계되었습니다.

## 주요 기능
- **자동 이동 알림**: 근무 이동 전(기본 5분 전) 및 종료 알림 제공.
- **맞춤형 알람 설정**: 알람 리드 타임(분) 조정 및 종료 알림 수신 여부 설정 가능.
- **편성표 및 근무표 관리**: 기본 제공 편성표 외에 커스텀 편성표 편집 기능 및 개인 근무표 사진첩 기능 제공.
- **순찰 도구**: 순찰 지점 체크리스트 및 관리 기능.

## 파일별 책임 범위 (Responsibility)

### 1. `MainActivity.kt` (진입점 및 권한 관제)
- **권한 관리 센터**: 앱 작동에 필수적인 권한들(`알림`, `정확한 알람`, `전체 화면 알림`, `다른 앱 위에 표시`, `방해 금지 무시`)의 상태를 총괄하고 획득을 유도합니다.
- **UI 컨테이너**: `MainApp` 컴포저블을 실행하고 `DutyRepository`를 통해 저장된 상태를 UI와 동기화합니다.

### 2. `DutyCalculator.kt` & `DutyModels.kt` (도메인 규칙 엔진)
- **비즈니스 로직의 심장**: 근무 편성표, PT 예외 규칙, 출퇴근 시간 계산 등 모든 '업무 도메인 지식'을 중앙 집중 관리합니다.
- **스케줄링 계산**: 단순히 근무 시작만이 아니라, 이동 시점 및 종료 시점을 계산하여 알람 데이터를 생성합니다.

### 3. `AlarmProvider.kt` (시스템 인프라 조절기)
- **스케줄링 실행**: `AlarmManager`를 사용하여 `DutyCalculator`가 계산한 시간에 시스템 알람을 예약/취소합니다.
- **알람 사운드 제어**: 알람 발생 시 벨소리 재생 및 진동을 관리합니다.

### 4. `AlarmReceiver.kt` (이벤트 브로드캐스트)
- **트리거 중계**: 시스템 알람 시간에 신호를 받아 화면을 깨우고 `AlarmActivity`를 호출하거나 알림을 표시합니다.

### 5. `AlarmActivity.kt` (전용 알람 인터페이스)
- **통합 알람 화면**: 잠금 화면 위나 다른 앱 사용 중에 나타나 사용자에게 이동 정보를 시각적으로 알리고 알람을 중단할 수 있는 기능을 제공합니다.

### 6. `DutyRepository.kt` (데이터 퍼시스턴스)
- **영구 저장소**: 사용자의 근무 설정, 앱 활성 상태, 커스텀 편성표(JSON), 등록된 이미지 경로 등을 `DataStore`를 통해 안전하게 보관합니다.

### 7. `MainApp.kt` & `ui/` 폴더 (UI 레이어)
- **UI 선언**: Bottom Navigation(홈, 근무표, 편성표) 및 Navigation Drawer(순찰, 알림 설정, 편성표 수정)를 포함한 전체 UI 구조를 정의합니다.
- **이미지 관리**: `ImageStorage`를 통해 사진을 앱 내부 저장소로 관리합니다.

## 근무 비즈니스 로직 (Business Rules)

### 1. 기본 규칙 (General Rules)
- **근무지 결정**: 선택된 **편성표**와 **나의 근무 번호**에 따라 각 시간대별 근무 장소가 결정됩니다.
- **알람 시점**: 각 근무 슬롯의 시작 시간 `leadTime`분 전과(설정 가능), 근무 종료 `finishLeadTime`분 전에 발생합니다.

### 2. 특수 규칙 (Special Rules - PT)
- **PT(Part-Time) 근무 적용**:
    - `LATE_START`: 전체 출근 시간이 30분 늦춰집니다 (예: 11:00 -> 11:30).
    - `EARLY_FINISH`: 전체 퇴근 시간이 30분 앞당겨집니다 (예: 17:00 -> 16:30).
- **유연한 슬롯 처리**: PT 적용 시 해당 시간 범위를 벗어나는 근무 슬롯은 자동으로 제외되거나 시간이 조정됩니다.
